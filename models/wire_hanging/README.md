# Hanging wire

Collada mesh: `meshes/wire.dae`. Closed, capped tube with a 2 m vertical drop, 2 cm diameter, and a gentle 12 cm sideways bend. Its centerline length is approximately 2.004 m.

The local origin is the top attachment point. Place the model origin at the ceiling; it extends downward along negative Z. The supplied static SDF uses the same mesh for visual and collision geometry. It represents a fixed shape, not a flexible cable simulation.

In the web app’s Merged map mode, click a ceiling point to position this top anchor. World Z moves the attachment point; uniform scale changes the complete mesh, including drop and diameter.
